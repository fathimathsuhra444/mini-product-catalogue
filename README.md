# Mini Product Catalogue

## Project Description
Mini Product Catalogue is a Django-based web application developed to manage and display different types of products. Users can browse products, search for items, view product details and place orders.

## Technologies Used
- Python
- Django
- HTML
- CSS
- Bootstrap
- JavaScript
- SQLite Database

## Main Features
- User Registration and Login
- Product Listing
- Product Categories and Subcategories
- Product Search and Filtering
- Product Details
- Add to Cart
- Favourite Products
- Order Management
- Online Payment Integration
- Admin Product Management

## Project Modules
1. User Module
2. Admin Module
3. Product Management Module
4. Shopping Cart Module
5. Order Management Module
6. Payment Module
